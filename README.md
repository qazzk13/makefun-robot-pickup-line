A pickup line from a warehouse robot that is nearly out of battery and knows it. It spends the last of its charge crossing the floor to plug in next to the robot it likes, which is about as romantic as a machine on wheels can get.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if you set that).
